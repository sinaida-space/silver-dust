# SILVER DUST

A browser tool that walks you through a structured set of questions about a project idea (title, problem, solution, target, metrics, scope, team and more) and exports the answers as a PowerPoint deck.

## Open it

https://sinaida-space.github.io/silver-dust/

It is a static page: open `index.html` in a browser. Answers stay in the browser.
